## 仿真平台使用

**最简方式**：双击 `simulator/index.html`（全部本地资源，离线可用）。

推荐方式（录屏演示用，避免任何浏览器限制）：

```bash
cd simulator
python -m http.server 8422
# 浏览器打开 http://localhost:8422
```

四个功能舱：

| 舱 | 内容 | 演示要点 |
|---|---|---|
| 01 设计舱 | 电池容量滑块 + 载荷勾选 → 重量堆叠/悬停功率/失速速度/合规判定实时复算 | 改参数即出结果，与文档共用同一套模型 |
| 02 性能舱 | 功率-空速极曲线、载荷-航时边界、能量瀑布图、顶风工况滑块 | 风场 0→4 m/s 对地航程 106→84 km |
| 03 任务舱 | A. 航测覆盖航线（GSD/重叠度/照片数/架次）；B. AI 巡检模拟（识别→事件流→自动成报） | 点"执行 AI 巡检任务"看全流程，约 18 秒 |
| 04 安全舱 | 作业合规检查器（国务院令第 761 号条款）+ 冗余降级策略矩阵 | 作业真高拖到 >120 m 看红条判定 |

工程模型位于 `assets/js/eng.js`（纯函数、注释齐全），平台与《一体化设计方案》数字完全一致；
设计基准数据由 `ENG` 模块导出：MTOW 5.220 kg / 悬停 866 W / 巡航 181.8 W / 航时 93.4 min / 航程 106.5 km / GSD 1.64 cm。

## 申报材料使用顺序

1. **读官方指南**：`竞赛资料/赛道指南全文.txt`——重点看"五（五）竞赛内容"“（八）申报材料规范”"（十三）违规淘汰"。
2. **通读两份 PDF**：先 `02-一体化设计方案.pdf`（技术主体），再 `01-作品介绍文档.pdf`（按官方字段的浓缩版）。
3. **改成本团队的信息**：两份 HTML 里所有"参赛团队/同济大学"等占位表述、团队成员、指导教师，用文本编辑器搜索替换后，浏览器打开 → 打印 → 另存为 PDF 重新导出。
4. **拍演示视频**：照 `03-演示视频脚本.md` 逐镜头录屏 + 配音，总时长控制在 8.5 min 左右（上限 10 min）。
5. **线上申报**：http://aiedu.caet.org.cn 注册 → 选"大学生 AI 创新创业组 → 低空装备技术应用赛道 → 科目一"→ 按 `04-申报书填报素材.md` 填写 → 上传材料。

## 重要合规提醒（必读）

1. **AI 生成内容必须人工审核**（指南"合规与安全总则"第 1 条）。本作品包由 AI 辅助生成，**提交前团队成员必须逐节复核、修改、内化**：核对每个数字、每处引用、每条法规条款；建议保留修订记录备查。
2. **如实标注**（指南第十一条第 2 款）：方案 §10.1 已预写研发工具与 AI 模型来源声明，按实际情况修订。
3. **原创性要求**（评分维度"创新优化性"第 1 条）：直接提交 AI 生成的文档存在被认定抄袭/代做风险的**比赛纪律风险**（指南"违规处置淘汰"第 1 条）。正确用法是把它当**底稿**：团队重算一遍计算书、重画三视图、按自己的理解改写方案、补充自己的实测/调研数据，让作品真正成为团队成果。
4. 工程模型为**方案级估算**（文档与平台已如实标注），不可声称为实测数据；样机验证计划见方案 §7。

## 技术备查

- 平台零依赖（无框架/无 CDN/无构建），字体本地打包（Figtree / JetBrains Mono / Material Symbols 子集）。
- 图标只能用字体子集里已有的名字（见 `simulator/index.html` 中 `<span class="sym">…</span>`），新增图标名会显示为文字。
- 平台截图验收：`Playwright` 全流程 0 console error；文档 PDF 由 Chromium `page.pdf()` 生成（A4，scale 0.93，含分页防截断规则）。
- 设计基准数据快照：`.shots/design_base.json`（由平台模型导出）。
